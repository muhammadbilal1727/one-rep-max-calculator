# One Rep Max Calculator

A free one rep max (1RM) calculator website: 7 formulas, a training percentage chart, strength levels, light/dark mode, and an SEO guide. Plain HTML, CSS and JavaScript, so there's nothing to install or build.

**Live site:** https://muhammadbilal1727.github.io/one-rep-max-calculator/

### 3. Google Analytics ID (optional)

In **site.js**, put your Measurement ID (looks like `G-ABC123XYZ`) between the quotes on this line:

```js
const GA_MEASUREMENT_ID = "";
```

Analytics stays off while it's empty. When you turn it on, also update the "Analytics and advertising" section of **privacy-policy.html** to say the site now uses Google Analytics.
